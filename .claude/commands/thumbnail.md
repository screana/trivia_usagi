サムネイルを作って、**実際に見て**確認する。

```bash
python -m src.thumbnail                      # config.THUMB_ITEM の項目で作る
python -m src.thumbnail --item 3             # 項目を指定して試す
python -m src.thumbnail --expression 困り
python -m src.thumbnail --no-mask            # 伏せ字を出さない
```

書き出したら `out/thumbnail_guide.png` を Read ツールで開いて確認する。

## どの雑学を選ぶか

**一番引きのあるものを選ぶ。台本の最後とは限らない。** 機械的に決められないので、
7つを読み比べて選び、`config.THUMB_ITEM` に書く(1始まり)。

引きが強いのはこの順で考える。

1. **自分の身体・生活のこと** — 見た人が自分を確かめたくなる
   (「耳垢が湿っている人は」など)
2. **誰でも知っているものの思い違い** — 前提が崩れる
   (「SOSは」「ネギトロの由来には」など)
3. **身近な物の意外な中身** — 手元にあるものが気になる
   (「柚子胡椒に」など)
4. 規模や数字の意外性 — 分かりやすいが自分ごとになりにくい

**釣りすぎない。** 振りは台本の文言をそのまま使い、大げさに書き換えない。
中身が伴わない引きは、見た人を裏切ることになる。

## 見る観点

- 振りの文字が小さくないか。サムネは一覧で小さく表示される
- うさぎの表情が内容と合っているか(驚き / 困り / 得意 / 感心 など)
- イラストとうさぎ、伏せ字が重なって潰れていないか
- 下部はアプリのUIに隠れるので、大事な要素を置かない

## 表情を変えるとき

使える表情は `config.EXPRESSIONS`。無ければ PSD から自動で作られる
(`python -m src.tachie --list` で選べるパーツが見られる)。
新しい表情を足すなら `config.EXPRESSIONS` に組み合わせを書く。体の姿勢は
`BASE_POSE` で固定してあるので、顔まわりだけ指定すればよい。

## 直すとき

数値は `src/config.py` の `THUMB_*` だけを触る。
