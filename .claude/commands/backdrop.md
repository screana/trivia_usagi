背景素材を増やす。**猫や犬など、落ち着いた動物の映像**を基本にする。

```bash
python -m src.backdrop --show                  # いま持っているものと出所
python -m src.backdrop --list "cat"            # 縦の候補
python -m src.backdrop --list "dog" --any      # 横の素材も見る
python -m src.backdrop --get 12345 --query "cat"
```

`PEXELS_API_KEY` が `.env` に要る(https://www.pexels.com/api/ で取得)。

## 選ぶときに見ること

背景は**文字を読ませるための下地**であって、主役ではない。

- **動きが遅いこと。** 走り回る映像や素早いカット割りは文字から目を奪う。
  寝ている・毛づくろい・ゆっくり歩く、くらいがちょうどいい
- **明るさが一定であること。** 途中で急に暗くなると白いベールを敷いても読めなくなる
- **中央に被写体がいること。** 横の素材は中央を切り出すので左右がかなり落ちる
- **尺は10秒以上。** 短いと1項目のあいだに繰り返しが目立つ
- 縦の素材(`--list` の既定)が取れるならそちらを優先する。切り出しで捨てる部分がない

**取得したら必ず確認する。**

```bash
python -m src.preview --item 1     # 背景が割り当てられた状態で描かれる
```

文字が読みにくければその素材は使わない。ファイルを消せば候補から外れる。

## 権利

**出所とライセンスは `assets/backgrounds/manifest.json` に自動で記録される。**
動画ファイル自体は git に入らないので、**記録だけがリポジトリに残る**。

- `--show` に「不明」と出る素材があれば、出所が追えていない。使わないか、
  手で manifest に追記する
- 手で置いた素材も必ず manifest に書く。書かないと `/publish` がクレジットを
  落とす
- Pexels License は商用可・表示義務なしだが、規約が「可能なら作者を明記する」
  としているので `credit` に作者を入れてある。概要欄に出す

## 背景を足したあとの影響

素材が増えると項目への割り当てが変わる(`BG_SHUFFLE_SEED` でシャッフルしている)。
書き出し済みの動画と見比べたいときは、素材を足す前後で別物になることに注意する。

初回の書き出しでは新しい素材の縦型変換が走るので、その分だけ時間がかかる
(`out/cache/bg/` に貯まり、2回目からは効かない)。
