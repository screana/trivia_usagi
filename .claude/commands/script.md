ジャンル「$1」で `script.json` を作る。

事実の誤りが最大のリスクなので、以下の工程は省略しない。

## 手順

1. **候補を20個程度出す。** いきなり7個に絞らない。この段階では粗くてよい

2. **1項目ずつ web 検索で裏を取る。** 次に当てはまるものは落とす
   - 出典が確認できない
   - 通説どまり(「〜と言われている」で一次情報にたどり着けない)
   - ソースが個人ブログのみ
   落とした理由も記録しておくこと

3. **残ったものから7個選ぶ。** 選ぶときに次を確認する
   - ジャンルが偏っていないか(生き物ばかり等)
   - オチの言い回しのリズムが揃いすぎていないか。「実は〜」構文が並ぶと単調になる
   - 振りが長すぎないか。`setup` は画面2行に収まる長さにする

4. `script.json` を書く。**書くのは読み上げるテキストだけ。** 画像・話者・速度は書かない

```json
{
  "title": "...",
  "items": [
    { "setup": "タコは", "punch": "メスのほうがおいしい" }
  ]
}
```

5. **`sources.md` に裏取りの根拠URLを残す。** 項目ごとに、採用した根拠と、
   落とした候補があればその理由も1行で書く

## 終わったら

`python -m src.preview --item 1` で1項目目を描いて、振り・オチが画面に収まるか確認する。
収まらなければ台本側の文言を短くする(レイアウトを変えない)。
