`out/preview_guide.png` を**実際に見て**指摘する。想像で書かない。

```bash
python -m src.preview --item ${1:-1}
```

書き出されたら `out/preview_guide.png` を Read ツールで開いて確認する。
赤い帯がセーフエリア(UIに隠れる領域)、緑の枠が安全域。

## 見る観点

- **セーフエリアからのはみ出し** — 文字が赤帯にかかっていないか
- **重なり** — 振り/オチ/出典表記/立ち絵が互いに重なっていないか
- **余白のバランス** — 上下に偏っていないか、要素間が空きすぎていないか
- **可読性** — フチが細すぎて背景に埋もれていないか、文字が小さくないか
- **円の中のイラスト** — 小さすぎないか、円からはみ出していないか

オチが2行になる項目と1行の項目の両方を見ること。行数で見え方が変わる。

## 直すとき

**数値は `src/config.py` だけを触る。** 他のファイルに座標を書かない。
直したら再度プレビューを出して、見て確認する。

## 判断の分担

明らかな事故(はみ出し・重なり・読めない)はここで潰す。
最終的な良し悪しは人間が決めるので、**好みの問題は指摘に留めて勝手に変えない**。

## ファイルを書き換えたら、当たったか確かめる

このリポジトリのファイルは CRLF で保存されている。Python スクリプトから
`str.replace` で書き換えると**一致せず無言で素通りする**ことが何度もあった。
「更新した」と報告したのに中身が変わっていない、という事故につながる。

- 書き換えは Edit ツールを使う(一致しなければエラーになる)
- スクリプトで置換するなら `assert 対象文字列 in 内容` を必ず入れる
- 書き換えた後は `grep` で結果を確認してから次に進む
