---
description: 読み上げの読み方を音声を聞く前にテキストで検証する
---

VOICEVOX の `/accent_phrases` は読みをカタカナで返すので、
**音声を作る前に**固有名詞や漢字の読み間違いを見つけられる。

```bash
python -m src.voice --check
```

台本の全テキストについて、原文と読み(カタカナ)を並べて出す。

## 見る観点

- 固有名詞が正しく読まれているか(人名・地名・商品名)
- 数字の読み方(「15センチ」→ ジュウゴセンチ / イチゴセンチ)
- 同音異義の漢字(「一日」→ イチニチ / ツイタチ)
- 不自然な区切り

## 直すとき

1. **台本側の表記を変える**のが第一手。「15センチ」→「十五センチ」など
2. それで直らなければ VOICEVOX のユーザー辞書に登録する

台本を直したら `--check` をやり直す。読みが変わっていれば音声も作り直される
(テキストが同じなら再生成しない)。
