description: 概要欄・タイトル案・ハッシュタグを作る
---

`script.json` と `assets/images/manifest.json` から投稿用のテキストを作り、
`out/publish.md` に書き出す。

## タイトル

**釣りすぎない。** 中身が伴わない煽りは、見た人を裏切って信用を落とす。

- 動画で実際に扱っている内容の範囲で書く。盛らない
- 「衝撃」「ヤバい」「9割が知らない」のような、根拠のない強調を使わない
- 数字を使うなら実際の数字だけ(「7選」は7つ入っているので可)
- 断定できないことは断定しない。台本が「〜らしい」なら題も言い切らない

案を3つ出す。全角30字前後に収める。**それぞれ何を狙った案なのかを一行で添える。**

## 概要欄

- 動画の内容(1〜2行)
- 各項目の一覧
- **VOICEVOX のクレジット**。動画内には出していないので概要欄に必ず入れる
  ```
  VOICEVOX:中国うさぎ
  ```
- **画像のクレジット**。`manifest.json` の `attribution` が null でないものは
  作者/ライセンスとURLを列挙する。いらすとやのみなら「イラスト: いらすとや」
- **BGM のクレジット**。`config.BGM` のファイル名が曲名なので、配布元の規約を
  確認して必要な表記を入れる
- **背景映像のクレジット**。ストック素材の規約による

## ハッシュタグ

5〜8個。動画の内容に対応するものだけにする。関係ないタグを混ぜない。

## 注意

中国うさぎには共通規約とは別にキャラクター個別の利用規約がある。
立ち絵に公式イラストを使っているので、収益化前にガイドラインを確認すること。
