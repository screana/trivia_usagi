雑学ショート動画を1本作る。**このファイルだけで最後まで通せるようにしてある。**

各工程には専用の手順書がある。**その工程に入る前に必ず該当ファイルを読むこと。**
ここに書いてあるのは流れと、外してはいけない点だけ。

## 始める前に

- **[AGENTS.md](../../AGENTS.md) を読む。** 守るべきことが書いてある
- **VOICEVOX が起動しているか確かめる。** `http://127.0.0.1:50021/version` が
  返らなければ、そこで止めて利用者に知らせる。後の工程が全部無駄になる
- **完成した動画は見られない。** 間の取り方やテンポの良し悪しは判断できないので、
  そこは利用者に委ねる。**判断できるのは静止画とテキストだけ**

## 手順

### 1. 最新にする

```bash
git pull
```

**飛ばさないこと。** 使用済みの雑学は手元の `episodes/*/record.json` から
数えている。pull しないと他の人が使った雑学が候補に残り、**同じ雑学を2回使う**。
git の衝突と違って**エラーにならないので誰も気づけない**。

### 2. 台本を作る

`.claude/commands/script.md` を読んで、その通りにやる。要点だけ:

- 新しい回を作る(`python -m src.episode --new "タイトル"`)
- DBから雑学を**7つ**選ぶ。ジャンルが偏らないように
- 振りとオチに割る。**振りでオチを言ってしまわない**
- **使った雑学IDを台本と同じ順で記録する**(`python -m src.trivia --mark …`)。
  忘れると次回また同じ雑学が候補に出る

### 3. 番号を押さえる

```bash
git add episodes/ && git commit -m "第N回の台本" && git push
```

回の番号は台本を作った時点で決まる。動画ができてから push すると、その30分の
あいだに他の人が同じ番号を取る。**ここで一度 push する。**

### 4. イラストを集める

`.claude/commands/images.md` を読んで、その通りにやる。7項目すべてに要る。

### 5. レイアウトを見る

`.claude/commands/review.md` を読んで、その通りにやる。

**書き出した画像を Read ツールで実際に開いて見ること。** 推測で「問題ない」と
報告しない。**行数で見え方が変わる**ので、振りが1行の項目と2行の項目の両方を見る。

事故があれば `src/config.py` の数値だけを直す。他のファイルに座標を書かない。

### 6. 読み方を確かめる

`.claude/commands/voicecheck.md` を読んで、その通りにやる。

```bash
python -m src.voice --check
```

固有名詞や数字の誤読は、**台本の表記を変えて直す**のが第一手
(「15センチ」→「十五センチ」など)。直したら `--check` をやり直す。

### 7. 音声を作る

```bash
python -m src.voice
```

30秒ほど。エンドカードの「毎日雑学更新中！」もここで一緒に作られる。

### 8. 動画を書き出す

```bash
python -m src.build
```

**4分以上かかる。止まったと判断して打ち切らないこと。**

終わったらログを確認する。**`うさぎの一言:` の行が出ていなければ**
エンドカードの声が入っていない。`python -m src.voice` からやり直す。

### 9. サムネイルを作る

`.claude/commands/thumbnail.md` を読んで、その通りにやる。

**7つのうちどれが一番引きがあるかを選んでから**作る。台本の最後とは限らない。
作ったら**実際に開いて見る**。**釣るために振りの文言を書き換えない。**

### 10. 概要欄を作る

`.claude/commands/publish.md` を読んで、その通りにやる。

**クレジットを落とさない。** VOICEVOX は必須。イラスト・BGM・背景映像も
manifest から拾って書く。**タイトルは釣りすぎない。**

### 11. 記録を共有する

```bash
git status        # 必ず中身を確認してから
git add … && git commit && git push
```

**`.env` と素材ファイル(動画・音声・イラスト・背景)を絶対に含めない。**
`.gitignore` で弾いているが、`git status` で目視確認してから add する。

## 進め方

**各ステップが終わったら結果を見せて、次に進む前に一度止まる。**
勝手に最後まで走らない。

**判断に迷ったら聞く。** 特に雑学の選定・サムネの選定・タイトルは、
機械的に決められないので独断で進めない。

途中で手順書に書いていない判断をしたら、**その理由を残す**
(README または該当の手順書を更新してからコミットする)。
